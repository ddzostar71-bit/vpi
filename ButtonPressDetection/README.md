# Обнаружение нажатия кнопки с FreeRTOS

Проект для лабораторной работы на платформе STM32G474 с использованием FreeRTOS.

## Описание задачи

Программа реализует систему обнаружения одинарного и двойного нажатия кнопки с индикацией через светодиоды:

- **Задача 1 (ButtonTask)**: Отслеживает нажатие кнопки PB15 и различает:
  - **Одинарное нажатие**: одно нажатие кнопки
  - **Двойное нажатие**: два нажатия в течение 1 секунды

- **Задача 2 (LEDTask)**: Принимает информацию через очередь FreeRTOS и отображает тип нажатия:
  - **Одинарное нажатие**: мигает LED1 (PE0) 3 раза
  - **Двойное нажатие**: мигают оба LED1 и LED2 (PE0, PE1) 3 раза

- **UART**: Выводит отладочную информацию на переднюю панель стенда через USART3 (115200 8N1)

## Аппаратная конфигурация

### Микроконтроллер
- **MCU**: STM32G474RETx
- **Частота**: 170 MHz (PLL от HSI)

### Пины

| Периферия | Пин | Описание |
|-----------|-----|----------|
| Кнопка | PB15 | Вход с подтяжкой вверх (нажата = LOW) |
| LED1 | PE0 | Выход для светодиода 1 |
| LED2 | PE1 | Выход для светодиода 2 |
| UART TX | PC10 | USART3_TX для вывода на панель |
| UART RX | PC11 | USART3_RX для приема данных |

### Параметры UART
- **Скорость**: 115200 бод
- **Биты данных**: 8
- **Четность**: нет
- **Стоп-биты**: 1

## Архитектура программы

### FreeRTOS компоненты

1. **ButtonTask** (приоритет: Normal)
   - Опрос кнопки каждые 10 мс
   - Дебаунс 50 мс
   - Детектирование одинарного/двойного нажатия
   - Отправка данных в очередь

2. **LEDTask** (приоритет: Normal)
   - Ожидание сообщений из очереди
   - Индикация типа нажатия через светодиоды

3. **ButtonQueue**
   - Размер: 5 элементов
   - Тип данных: ButtonPressType_t (enum)

### Логика обнаружения нажатий

```
Нажатие 1 → Ожидание 1 сек → Нажатие 2?
                │                  │
                │                  ├── ДА → Двойное нажатие
                │                  │
                └── Таймаут → Одинарное нажатие
```

## Как использовать

### Импорт проекта в STM32CubeIDE

1. Откройте STM32CubeIDE
2. File → Import → Existing Projects into Workspace
3. Выберите папку `ButtonPressDetection`
4. Нажмите Finish

### Открытие в STM32CubeMX

1. Откройте файл `ButtonPressDetection.ioc` в STM32CubeMX
2. При необходимости измените конфигурацию
3. Сгенерируйте код: Project → Generate Code

### Сборка и прошивка

1. В STM32CubeIDE выберите проект
2. Project → Build Project
3. Подключите программатор ST-LINK к разъему на плате
4. Run → Debug (F11) или Run (Ctrl+F11)

## Технические детали

### Используемые библиотеки
- STM32 HAL Driver
- FreeRTOS CMSIS-RTOS v2
- CMSIS Core

### Конфигурация FreeRTOS
- **Heap**: 15360 байт
- **Tick Rate**: 1000 Hz
- **Preemption**: включен
- **Time Slice**: TIM6

### Особенности реализации

1. **Антидребезг**: программная задержка 50 мс после обнаружения фронта
2. **Таймаут двойного нажатия**: 1000 мс между нажатиями
3. **Неблокирующая работа**: задачи используют osDelay() для кооперативной многозадачности
4. **Безопасность**: очередь защищена от переполнения

## Возможные модификации

1. **Тройное нажатие**: добавить обработку третьего нажатия
2. **Долгое нажатие**: детектировать удержание кнопки > 2 сек
3. **Настройка таймаута**: сделать таймаут двойного нажатия конфигурируемым
4. **Больше светодиодов**: использовать остальные светодиоды PE2-PE15
5. **Звуковая индикация**: добавить пищалку на таймере PWM
